# V4 版本与留痕

版本：`v4.0.0`。开发分支：`codex/clay-refinement-v4`，从已发布 V3 `c8784bc` / `v3.0.0` 开始。

本版以用户上传的坐姿 GLB 精修；保留原坐姿与辨识特征，移除融合小龙虾、补圆头冠、整理扫描形体与烘焙色斑，制作哑光彩泥和独立背包。网页按坐姿重新取景，整体拖动与旋转使用按需绘制，并修复章节过渡中旋转被重置和近景侧转挤入文字的问题。

## 路线循环追加记录

本次从 V4 静态路线基线 `528ef15d9dbae70084b966643ba4846fc1e18035` 追加动效，保留上述模型交付与既有验收记录。已实现镜头缓转／呼吸光、8 层橙片错峰分合、括号与橙条节奏、11 条波形起伏；桌面和手机自动播放，可手动暂停，离屏／后台暂停，减少动态时静止。

`motion-before/route-{0..3}.png` 记录修改前生产页面；`motion-after/route-{0..3}.png` 与 `motion-after/loops.mp4` 记录修改后构图和四组静置循环。专项结果保存为 `route-motion-qa.json`。截图不证明动画变化，以连续录屏和时间采样为准。生产预览 `route-motion-qa.json` 共 10 项通过，确认四组持续循环、手动暂停与恢复保留相位、离屏停止、实时减少动态移除循环，以及 390px 触屏模拟下四组播放、16 条链接和无横向溢出。后台处理仅通过页面内模拟 `document.hidden`／`visibilitychange` 验证，不声称操作系统真实后台测试。手机原图为 `motion-after/mobile-route-{0..3}.png`。

专项检查和原速录屏可用 `scripts/verify-route-motion-v4.cjs` 与 `scripts/capture-route-motion-v4.cjs` 复现；`motion-after/capture-metadata.json` 保留浏览器原始时间戳采集信息。新版三视频报告另做展示检查；线上发布核验随后在外部留档。

## 最终模型

- 实际 Blender 多边形与网页三角面均为 **1,025,000**；主体 965,700、背包 59,300。
- 完整 GLB **29,364,716 bytes**，默认桌面与手机均加载完整精度。
- SHA-256：`e3c5eeb1fa3534707fa45cf74848b2dea20f3997be894bfc787e3a2ceb548c76`。
- 原用户 GLB **501,070 三角面**、16,039,824 bytes，SHA-256：`f196abdedb71ff60ed22014b88551f9f4c4f244b3b53d0de821f667bae4ec94c`，未覆盖。
- 可编辑母版 994,602 polygons；最终三角化文件与 GLB 的面数逐项一致。色区材质边界在 GLB 中拆分顶点，保存的 Blender 主体闭合；详见独立验证记录。

## 验证与展示

类型检查、lint、生产构建通过。浏览器测试覆盖四幕跳转、反向滚动、整体拖动、取消/失焦、静止零新增绘制、离屏恢复、五种宽度、原生触摸滚动、实时减少动态、加载延迟及失败回退。独立旋转测试验证滚动途中点击、四次回位及后续滚动恢复；最后的近景目标点微调另存定点检查。

`before/` 保存 V3 真正的截图和原始视频，`after/` 保存最终模型与网页截图、约 47 秒原速录屏。`source-inspection/` 保留上传 GLB 原始检查；`iterations/` 保留两轮未通过材质效果和修正原因。报告支持离线打开、键盘移动比较分界、播放本地视频，在线与离线均已检查。

录屏和测试来自桌面 Chrome 及触摸模拟，不宣称真实手机 FPS、加载速度或转化率改善。最后的近景自由旋转避让不改变录屏中的预设四幕取景。
