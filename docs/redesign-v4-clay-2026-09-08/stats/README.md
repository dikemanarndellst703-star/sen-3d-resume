总数包含独立背包。背包静态部件按材质合并成四个 mesh，与连续的原角色派生本体共五个 mesh；GLB 本体因七个材质导出为七个 primitives，primitive 数不等于 Blender 对象数。

最终 `.blend` 已显式三角化。母版是预算调整后的可编辑混合拓扑，不是纯四边形重拓扑版本。GLB 顶点会因材质/属性边界重新拆分，因此独立 GLB accessor 顶点数可能与 Blender 顶点数不同，但实际三角面数必须一致。

原始输入和 V1–V3 哈希、二进制索引计数、最终 `.blend` 重开和 GLB 重导结果由独立验证脚本写入 `../verification/`。最终渲染和海报只对应上述 hash；第一、二轮未通过图在 `../iterations/` 中保留。
