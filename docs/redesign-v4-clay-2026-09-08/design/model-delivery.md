# V4 泥塑模型：源网格修整记录

本轮角色来自用户上传的坐姿 GLB。生成脚本默认读取仓库内字节一致的 `web/public/models/ai-hamster.glb`，先验证 SHA-256，再创建新资产；未调用 V3 角色生成器，未覆盖源模型或 V1–V3。

## 形体与去虾

原模型的虾、头、身体在位置焊接后属于一个连通整体。脚本依据源贴图红色区域的连通性识别虾体，配合高度和邻域选区移除深色触须及接触区。两侧耳杯有空间保护区，不按一条水平线切掉整个头顶。

圆头由原有完好金色头皮的上向表面拟合，使用稳健二次曲面构造与现存切边连接的补片，再对这个连续的原角色网格进行体素重采样。修补并非叠加另一顶帽子。原 UV 接缝造成的分裂、局部切边分叉和补片扇形三角经连续重网格合并，最终用实际边统计验证封闭性。

全角色重采样会改变原始拓扑；“保留源模型”指沿原几何修整并保留坐姿、收手、脚掌、脸型和眼镜特征，不是声称顶点索引或 UV 未变。头顶、后脑、下巴和肚皮使用不同的平滑权重，保护眼睛、鼻嘴、耳窝和手足。灰模的正面、背面、侧面及俯视留在 `draft/`，用于核对去虾及修补过程。

## 表面与颜色

源贴图含有烘焙亮斑、阴影与 UV 分片边缘，不能直接作为无光照底色继续使用。新网格先查询最近的原始源点，以原始坐标和颜色识别金色、奶油、粉色、腮红、炭灰镜框/眼睛、褐色鼻嘴等区域，再映射到受控的哑光泥塑调色板。新头冠恢复金色；不将原虾红色或明暗斑块重新投射回来。

区域清理由网格邻接关系的小范围多数投票完成，没有全局模糊 2D atlas。颜色转换明确区分源 sRGB 采样和 Blender 线性颜色。输出使用顶点颜色和可导出的标准 PBR 材质，不依赖仅能在 Blender 内运行的程序着色器。

泥塑微起伏直接写入几何：低幅随机颗粒与柔和工具拖痕沿法线位移，眼镜、眼睛和鼻嘴采用更低幅度。最大绝对幅度上界约为源坐标 0.000195，归一到 3.6 高度后仍保持轻微。细节不使用毛发，不把大尺度扫描波浪当成手工质感。

## 独立背包

`ClayBackpack` 是独立于仓鼠本体的配件组。包体、前袋、宽肩带、浅压线、针脚、双拉链轨、圆润小齿、拉环和提手均是实际几何；静态部件按四种材质合并，便于网页加载与 Blender 编辑。颜色为低饱和棕色，五金同样是哑光泥塑。

背包在源坐标中贴合坐姿背部，肩带沿外肩结束于手臂上方，避开腹前手势。原尾巴保留。配件与身体保持独立，部件之间存在有意的连接重叠，不能将整个资产误称为单一可打印流形实体。

## 精度与交付契约

最终模型先生成足够密度的表面，再依据背包实际三角面数分配整体约 102.5 万面的预算。完整资产用于默认网页加载；最终 `.blend` 显式应用三角化，因此实际 polygon 数和三角面数一致。可编辑母版另存，但预算调整后的本体已经含三角面，母版不能宣传为纯四边形拓扑。

精确的最终面数、顶点数、文件字节数、SHA-256、母版 polygon/triangle 数和封闭边结果见 `../model-stats.json`；独立导出与重导验证见 `../verification/`。源模型的 501,070 面与新资产必须分别统计，不能用“翻倍”代替测量。

`HamsterRoot` 控制完整角色，`ClayBackpack` 控制背包。上传模型没有可分离头眼手骨骼，本轮也没有添加虚构关节；运行时适用整体拖动和整体旋转。导出 glTF 为 Y 上、+Z 朝前，仓鼠本体高 3.6，地面原点。灯光和相机仅保存在 Blender 场景中，不导出到 GLB。

## 可复现入口与视觉证据

从仓库根运行 `Blender --background --python blender/refine_hamster_v4_clay.py`。设置 `CLAY_FINAL=0` 可重建灰模手术阶段；默认执行最终表面、配件、百万面导出和多视图渲染。辅助模块为 `blender/clay_color_regions_v4.py`、`blender/clay_backpack_v4.py`。

`source-inspection/` 是未经修改的源渲染，`draft/` 是去虾后无纹理灰模，`renders/` 是最终中性光下的正面、背面、侧面、斜侧面、头部、头顶和背包细节。`after/model-front.png`、`model-back.png`、`model-detail.png` 为报告副本。网页 poster 来自实际最终 Blender 斜侧面渲染。

这些渲染证明形体、材质与配件的外观；浏览器灯光、机位、加载及交互表现另由网页端验收。百万面和文件大小不是实际设备帧率测试。
