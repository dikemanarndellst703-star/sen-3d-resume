# V3 · 旗舰宣传页重设计

基线 `v2.0.0` / `4c8c4f9`。用户明确否定上一版模型和页面滑动，要求约 100 万面的模型，并参考南孚、小米海外宣传网站。

## 方向与验收目标

采用旗舰产品发布页叙事：整屏大主角、近景摄影、留白与黑白灯光转换、少量大标题。滚动驱动相机的明确旅程，镜头、材质照明和文字使用同一进度。移除 V2 的环形玩具探索舱、悬浮小图标、摸摸/转圈/日夜按钮组以及小卡片路线布局。

字体使用 Helvetica Neue / PingFang SC；正文清晰，中文主标题约 80–112px（桌面）。纸白 `#f3f3f0`、近黑 `#0b0d10`、雾灰 `#d9dad8`、品牌珊瑚橙 `#e7634d`。不使用第三方品牌 logo、产品图或商标来代替 AI 仓鼠洞资产。

## 摄影分镜

1. **出场**：白色无边摄影棚，完整角色三分之二侧前视角；大标题表达核心价值，CTA 始终可直达。
2. **看见细节**：滚动推近眼镜、眼睛与脸颊，转为深色摄影；单条文案出现，其余文案退场。
3. **开始探索**：相机拉开并与角色旋转协同，展示侧后背包；强调从问题到作品的实践。
4. **打开可能**：回到完整角色和宽幅构图，过渡到学习路线。侧边章节索引支持直接跳转，底部可以跳过展示。

浏览器保留原生滚动。桌面摄影区域 sticky，滚动进度经弹簧平滑后同时驱动相机和文案。用户可拖动角色看不同角度；触屏保留纵向滚动。系统减少动态效果时使用静态摄影与顺序内容，保留所有链接。

## 模型与性能

默认网页加载的 V3 GLB 本身包含至少 1,000,000 三角面，不把高模只放在截图或 Blender 中。建模增加真实轮廓和结构细节，保留可编辑 Blender 源与节点。报告同时记录 polygon 和 triangle 数，避免混淆。

使用环境反射和摄影棚灯光；减少额外实时阴影渲染，控制 DPR、离屏暂停，避免百万面叠加多个昂贵后处理。文件大小、顶点数、面数和绘制调用独立报告，不把面数或主观观感当成帧率提升。

## 下半部与留痕

学习路线采用整幅叙事切换，保留 16 个真实内容入口；移动端自然纵向展示。关于 Alex 保留五项经历、15 个要点及原有数字。V2 的源码、模型和报告保持原样，V3 另建报告目录，保存相同视口对比、真实滚动视频、模型统计、浏览器验证与发布凭证。
