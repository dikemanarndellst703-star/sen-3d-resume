# AI 仓鼠洞 · 探索舱改版设计

日期：2026-09-08。基线：`d44d71ee9809357a1be50da1c42d989d36d7df4a`。模式：Redesign · Overhaul。

## 产品与保留边界

面向 AI 新手，把好奇心转化成明确的学习路线，最终进入 https://ai.alexdbg.com/ 。保留原 LOGO、眼镜仓鼠的识别特征、Alex 的五段经历、原有教学成果表述与全部 16 个学习条目；外链继续新窗口打开。`#alex-story` 保留，增加 `#learning-map`。原模型、原 Blender 文件保持不变。

## 视觉设计

首屏是展出收藏级仓鼠公仔的微缩探索舱：角色是主角，环形舱门、分层基座、悬浮学习道具提供空间深度。使用真实可编辑 Blender 模型与实时 WebGL。首屏与关于 Alex 共用一个画布，通过镜头与角色朝向建立连续性；学习区变为深色，强调任务选择。

主要观看距离为桌面与手机。气质友好、精致、好奇。首屏左文右景，手机上文下景；About 采用可展开经历，避免连续多屏重复排版；学习路线选项与内容即时对应。

校准：视觉变化 8 / 动效 7 / 密度 4 / 资产依赖 9 / 品牌忠实度 7。

- Paper sage `#e9eee5`：主背景。
- Forest ink `#25382e`：标题与学习区背景。
- Cream `#fff8e9`：模型脸部、舱门与亮色文字。
- Coral `#e7634d`：主要行动与触发反馈，承接旧品牌。
- Moss `#7f927a`：辅助说明、场景底座。
- 中文标题/正文使用本机 PingFang SC / Microsoft YaHei；英文展示字体 Georgia，标签 Helvetica Neue。无外部字体阻塞。
- 8px 空间基数；4px 微调；按钮胶囊，场景大圆，面板 24px。阴影主要属于真实 3D 物体，HTML 控件只用浅阴影。

## 动效与因果

1. 入场：文案短错峰出现；加载只覆盖 3D 区域，始终可使用导航与 CTA。
2. 指针：头和眼睛限幅跟随，镜头微视差，不替换系统光标。
3. 摸摸：角色短弹跳、挥手及文字回应；触屏/键盘有等价按钮。
4. 转一圈：角色自转一周后回到原姿态，可观察建模背面。
5. 日夜：照明和环境在同一画面内平滑过渡。
6. 滚动：原生滚动驱动相机从迎接到侧前方观察，帧率独立指数阻尼；不劫持滚轮。
7. About：五项折叠经历，展开引发轻微镜头转向；保留原全部事实文字。
8. 路线：四个 tab 对应真实内容，支持方向键/Home/End；切换插画与强调色，保留全部原链接。
9. 离屏停止画布渲染；移动端降低像素比；减少动态模式关闭连续动作和自动视差，用户仍可主动选择。

UI 反馈 180–250ms；内容切换 320ms；人物回应约 1.2s；转身约 2s。缓动以 `cubic-bezier(.22,1,.36,1)` 为主。
