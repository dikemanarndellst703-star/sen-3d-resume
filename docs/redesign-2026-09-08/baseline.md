## 原版结构与视觉

- 内容结构：首屏引流 → Alex 的 5 项经历 → 4 条 AI 学习路线 → 收尾引流。
- 主转化目标保持为 `https://ai.alexdbg.com/`。首屏、固定入口、最后一项经历、路线列表及结尾均通向学习站。
- 原版品牌：真实 AI 仓鼠洞 logo；仓鼠戴黑框眼镜，头顶红色小伙伴；米色背景、暖白文字、珊瑚橙 CTA。
- 色彩变量：墨字 `#fff7e9`、燕麦 `#c8af90`、可可 `#3b2d25`、珊瑚 `#e7634d`、鼠尾草 `#66735b`、深墨 `#2a211b`。
- 字体：正文优先 Helvetica Neue / Chiron GoRound TC / PingFang SC；标题以 Cormorant Upright 配合中文 Chiron GoRound TC。HTML 从 Google Fonts 请求 Mansalva、Cormorant Upright 和 Chiron GoRound TC。
- 首屏标题位于角色前方中央偏下，logo、文字、按钮、成果数据均叠加在角色前方。经历靠右，左侧角色随滚动换角度。路线卡片铺满高度，宽度为 `min(820px, 76vw)`。
- 两个 WebGL Canvas：一个主场景，一个噪点叠层。噪点层 `multiply`，不透明度 0.5，z-index 100，每秒触发一次更新，因此颗粒也覆盖文字和按钮。

## 原版 3D 的真实基础

原模型 `web/public/models/ai-hamster.glb` 为 Tripo 导出，15.30 MiB（16,039,824 字节）。结构如下：

| 指标 | 原版 |
| --- | ---: |
| 顶点 | 290,841 |
| 三角面 | 501,070 |
| Mesh / primitive / material | 各 1 |
| 贴图 / 图像 | 各 1 |
| 骨骼蒙皮 | 0 |
| 内置动画 | 0 |

它已是高面数静态模型；原版的活动来自整体位移、整体旋转与相机运动。单一合并网格没有可单独驱动的眼睑、手臂或红色伙伴。提升精细度应关注造型层次、材质分区与可动部件，不能仅用增加面数判断。

场景参数：角色 scale 4.8、位置 `[0, -2.38, 0]`、初始 Y 轴旋转 `-π/2`；主画布 DPR 限制 `[1, 1.5]`，FOV 36，ACES 电影色调映射；环境光 1.55，半球光 1.4，方向光 3.1（1024 阴影贴图），珊瑚色聚光 18；背景和雾均为 `#c8af90`，雾区间 12–28，地面接收不透明度 0.2 的阴影。

## 本次升级应解决的可见问题

1. **主角与主标题争夺同一区域。** 桌面和手机都能看到 logo／标题盖住脸与眼镜，难以同时看清品牌角色和引流信息。
2. **颗粒覆盖全部层级。** 0.5 不透明度噪点抹平了材质细节，也降低正文和按钮的清晰度。截图保留这个真实旧效果。
3. **高面数没有转化为丰富角色互动。** 单一网格只能整体摆动，尚无眨眼、看向用户、独立红色伙伴动作或触摸反馈。
4. **浏览路径较长。** 五项经历有较大的屏间留白，学习路线起始再保留一整屏横向留白。对首次到访者，获取学习路线需要较长滚动。
5. **交互主要依赖滚动和 hover。** 缺少路线主动选择、角色回应、即时状态反馈，手机无法获得桌面的指针视差。
6. **减少动态效果支持不完整。** CSS 降速并不会停止实时 3D 与 Framer Motion 动态，应在下一版统一控制。
7. **字体仍依赖外网请求。** 本次正常加载，但若网络不可达则会改变中文表现和换行，后续应明确本地字体或系统回退策略。

这些是基于源代码和真实画面的设计审计，不是流失率、转化率或 FPS 的测量结论。
